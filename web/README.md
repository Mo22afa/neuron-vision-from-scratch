# Neuron Vision — interactive website

A responsive React + Vite app that runs the **original trained NumPy MLP weights entirely in the browser**.

## Development

From the repository root:

```bash
pip install -r requirements.txt
python -m src.train
python -m src.export_web_model
cd web
npm install
npm test
npm run dev
```

The web app expects `web/public/model.json` and `web/public/examples.json`, generated by `src/export_web_model.py`. These are exported from the same weights used by the Python classifier, not retrained in JavaScript.

## Architecture

- **Input:** canvas is centered/cropped, antialiased, downsampled to 8×8 and normalized to 0..1.
- **Hidden layer:** 32 tanh neurons.
- **Output:** 10 softmax probabilities.
- **Visualization:** true hidden activations and selected high-contribution connections (not all 2,368 connections).
- **Examples:** one held-out scikit-learn Digits image for each digit.
- **Validation:** `npm test` checks all ten JavaScript predictions and probabilities against Python's original model.

The test accuracy (98.15%) is on the original held-out Digits data; freehand browser drawings differ from the training distribution, so real-world drawing accuracy can be lower.

## Publish

The GitHub Pages workflow builds from `web/` with the repository base path `/neuron-vision-from-scratch/`. If the repository has not enabled Pages yet, go to **Settings → Pages → Build and deployment → Source: GitHub Actions**, then rerun the workflow.
